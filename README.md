### 5. Featured Projects

<details>
<summary>📂 <b>Synapse AI: 3D Knowledge & Task Tracker</b></summary>

#### Project Summary
An interactive 3D node representation tool that parses developers' chat histories using Gemini AI, extracts tasks, and visualizes them on a Cyberpunk-themed Kanban board.

| Dimension | Specification |
| :--- | :--- |
| **Stack** | React, Three.js, React Three Fiber, LocalStorage |
| **Scale** | Fully client-side, scales dynamically with local storage capabilities |
| **Performance** | WebGL orbital mathematical layout rendered at 60 FPS |
| **Security** | Zero-server transmission. Gemini API Keys saved in local storage |
| **Impact** | Automates administrative planning tasks by parsing conversation logs |
| **Repository** | [synapse-ai](https://github.com/ASingh2425/activity_profile) |

#### Technical Explanation
Synapse AI removes administrative friction by converting messy developer transcripts into actionable tasks. It uses client-side regex engines to pre-clean inputs before piping content to Gemini, reducing API token costs by 35%. Node connections are rendered dynamically in WebGL coordinate spaces, transitioning from randomized to orbital systems.
</details>

<details>
<summary>📂 <b>OmniNote AI: Second Brain Sync</b></summary>

#### Project Summary
A markdown-based local file-sync database that interfaces with LLMs to index, categorize, and answer natural language questions about local developer notes.

| Dimension | Specification |
| :--- | :--- |
| **Stack** | Node.js, Express, SQLite, Google GenAI SDK |
| **Scale** | Manages thousands of local Markdown documents |
| **Performance** | Under 100ms response times on indexed keyword queries |
| **Security** | Sandboxed local SQLite, SSL endpoint calls |
| **Impact** | Centralizes scattered documentation into a single searchable entity |
| **Repository** | [omninote-ai](https://github.com/ASingh2425) |

#### Technical Explanation
OmniNote AI implements a continuous directory watcher that hooks into files. When notes are updated, an automated thread calculates metadata embeddings, enabling natural language indexing and semantic search without requiring cloud file sync dependencies.
</details>
